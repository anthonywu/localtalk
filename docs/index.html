Fully offline

Turn off WiFi. It still listens, reasons, and speaks. Core STT/LLM/TTS never touch the network.

🔒

100% private

Your conversations never leave the device. No accounts, no telemetry, no third-party calls.

🚫

Zero API keys

No API bills to rack up. Hand it to a student or a kid and let curiosity run — it costs only electricity.

Apple-native

AVFoundation Speech, on-device Foundation Models on macOS 27, and the free native Tingting voice.

Features

Everything you'd want from a modern assistant. Without the cloud.

A real end-to-end voice loop — speech recognition, reasoning, and natural speech synthesis, all running on your machine.

⚡

Sentence-streamed speech

It speaks the first finished sentence the moment the model produces it — no waiting for the whole reply to synthesize.

🎙️

Auto-listen VAD

Silero VAD detects when you start and stop speaking. No button-pressing — just talk.

📊

Live waveform

A real-time Unicode waveform shows your mic levels as you speak, so you always know it's hearing you.

🧠

Mid-session reasoning

Say “think harder” or “think faster” and it adjusts its own reasoning level on the fly — no restart needed.

📚

Offline knowledge packs

Ask it to download Simple English Wikipedia into your cache, then query it offline — great for classrooms and travel.

🌐

Online tools, opt-in

When you're online, web search and a local browser turn on automatically. Say “disable web” anytime — only tools leave the machine.

💬

Type or speak

Dual input: press Esc during auto-listen to switch to the keyboard, Esc again to go back to voice.

🌏

Bilingual voices

ChatterBox Turbo for English, plus the free native Tingting and optional Qwen3-TTS for Mandarin Chinese.

🕒

Datetime-aware persona

A warm default persona that knows what “today” is, overridable with your own prompt file or inline text.

Design philosophy

Deliberate scope, a few strong opinions.

Apple-native, end to end

All Apple platform capabilities are in scope. Where an Apple API — AVFoundation Speech, on-device Foundation Models, the Tingting voice — beats a cross-platform library, localtalk prefers it.

macOS-first, latest-first

We optimize for the newest macOS and adopt new platform features as soon as they land. Older releases get best-effort fallbacks, not release blocks. Linux is in scope, but not prioritized.

Terminal-first, terminal-only

A GUI is explicitly out of scope. Keeping the interface textual keeps the iteration loop tight — the same CLI a human drives is what runs the tests and evals. Want a GUI? Wrap the CLI.

Built for tinkerers & learners

For DIYers, educators, parents, and learners who want to understand and modify — not just consume. Zero accounts, one-command install, everything inspectable on disk.

Why "LocalTalk"?

An homage, on two levels.

The name is a playful nod to Apple's classic LocalTalk networking protocol from the 1980s. Just as the original LocalTalk connected Apple devices without external infrastructure, this LocalTalk carries on AI conversations without external cloud services.

It works on two levels: Local — everything runs on your Mac, no internet required after setup. And Talk — it's literally a talking app that listens and responds with voice. The perfect name for an offline assistant in the Apple tradition of powerful, self-contained technology.
