Terminal preview: localtalk starts Whisper, the language model, and text-to-speech, then listens and answers in voice.

Fully offline

Turn off Wi‑Fi. It still listens, reasons, and speaks. Core speech and model steps never need the network after setup.

Private by default

Conversations stay on device. No accounts, no telemetry. Network only when you enable tools — say “disable web” anytime.

Zero API keys

No token meter. After download it costs electricity — teach and experiment without racking up bills.

Built for Mac

Prefers on-device platform capabilities: system speech synthesis, MLX on Apple Silicon, Foundation Models when available.

Features

A modern voice loop. Without the cloud.

The product is speech in, model thinks, speech out. Knowledge packs, web, and browser tools are power features you opt into.

Voice loop

Sentence-streamed speech

Speaks the first finished sentence the moment the model produces it.

Auto-listen VAD

Detects when you start and stop speaking. No button-pressing — just talk.

Type or speak

Press Escape to switch to the keyboard, Escape again to return to voice.

Live waveform

A real-time Unicode waveform shows mic levels so you know it’s hearing you.

Bilingual voices

ChatterBox Turbo for English; system Tingting and optional Qwen3-TTS for Mandarin.

Mid-session reasoning

Say “think harder” or “think faster” — no restart required.

Power features

Offline knowledge packs

Cache Simple English Wikipedia and query it offline — classrooms, travel, airplane mode.

Web under your voice

Optional online tools when you want them. Only tools leave the machine.

Teachable and forkable

Prompts, tools, and models on disk. Read the loop, change the persona, ship a classroom variant.

Design philosophy

Deliberate scope, a few strong opinions.

Inspired by the same fundamentals as Apple’s Human Interface Guidelines — clarity, deference, and depth — applied to a terminal-first voice product.

Platform-native, end to end

Where an on-device Apple API — system speech synthesis, Foundation Models, the Tingting voice — beats a cross-platform library, localtalk prefers it.

macOS-first, latest-first

Optimized for the newest macOS. Older releases get best-effort fallbacks, not release blocks. Linux is in scope, not prioritized.

Terminal-first, terminal-only

A GUI is out of scope. The same CLI a human drives is what runs tests and evals. Want a GUI? Wrap the CLI.

Built to teach with

Understand, fork, and teach — not just consume. Kids in scope with parental guidance. Zero accounts, one-command install, everything inspectable on disk.

Why “LocalTalk”?

An homage, on two levels.

The name is a playful nod to Apple’s classic LocalTalk networking protocol from the 1980s. Just as the original LocalTalk connected Apple devices without external infrastructure, this LocalTalk carries on AI conversations without external cloud services.

Local — everything runs on your Mac after setup. Talk — it listens and responds with voice. A self-contained assistant in the tradition of powerful technology that stays yours.
